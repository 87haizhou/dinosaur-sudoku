# 🦕 侏罗纪数独 - Jurassic Sudoku

一个融合古生物知识的数独游戏，包含180个物种，跨越寒武纪到第四纪。

## 在线游玩
👉 [点击开始游戏](https://yourusername.github.io/dinosaur-sudoku/)

## 关于
- 180道数独关卡，对应180种古生物
- 难度分为：起源、昌盛、灭绝
- 关卡命名参照 ICS 2024 地质年代表
- 收集动物卡片，探索生命演化历程

## 技术栈
- 纯 HTML/CSS/JavaScript 单文件应用
- AI生成恐龙图片（腾讯混元大模型）
- Wikipedia古生物插图
